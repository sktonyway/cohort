# 📓 React Native Notes App
This project is a high-fidelity, responsive Notes Application built with React Native. It features a clean visual hierarchy, theme-adaptive styling, and a seamless editing experience.

## 🚀 Project Overview
- The primary dashboard for navigating and searching through saved notes.

- List Rendering: Powered by FlatList for performance and smooth scrolling.

- Note Cards: Each card is wrapped in a Pressable component and displays:

- Title: Bold, clear typography.

- Snippet: A short preview of the note content.

- Timestamp: The last edited or created date.

- Search Functionality: A TextInput at the top to filter notes in real-time.

- Appearance Toggles: Integrated switches for Dark Mode, Light Mode, and a Focus Mode.

- Visual Design: Focused on proper spacing, structured card layouts, and readable typography.

A dedicated environment designed for long-form writing and content creation.

- Input Fields: * A single-line TextInput for the title.

A multiline TextInput for the body text.

- Keyboard Management: Wrapped in KeyboardAvoidingView to ensure input fields remain visible and accessible when the keyboard is active.

- Header UI: Features an ImageBackground to add a polished, modern aesthetic.

- Custom Controls: Pressable components used for Save and Back buttons, ensuring responsive touch feedback.

- Ergonomics: Spacing is optimized to maintain comfort during extended typing sessions.

#### 🌓 Theme Handling
The app utilizes useColorScheme() for automatic detection of system themes. The UI dynamically adapts its color palette for both Dark and Light modes.

#### 📱 Responsive Layout
We use useWindowDimensions() to ensure the layout remains consistent and functional across:

Standard Smartphones

Large-format Tablets

Variable screen orientations

#### 🛠 Styling Rules
All UI elements follow strict React Native styling patterns:

Centralized Styles: Built exclusively with StyleSheet.create().

Advanced Logic: Utilizes StyleSheet.compose() or StyleSheet.flatten() for managing conditional styles and theme overrides.

Zero Inline Styles: To maintain codebase cleanliness and performance.

#### 🛠 Tech Stack
Framework: React Native

Language: JavaScript (ES6+)

Styling: StyleSheet API

Layout: Flexbox
